## Deployment

This site is designed for GitHub Pages deployment and uses relative links so it works correctly in a repository deployment context.

## How to update the portfolio

- Resume: replace the file at `assets/documents/Renuah-Samuel-Resume.pdf` with the final PDF.
- Projects: update sections inside `index.html` and the project modal data in `js/script.js`.
- Certifications: update the certification cards in `index.html`.
- Contact details: adjust the contact section in `index.html`.
- Images: place project or profile visuals in `assets/images/`.

## GitHub Pages setup

1. Create a repository named `renuah1142.github.io` or use another repo name.
2. Push the project files to the repository.
3. Go to Repository → Settings → Pages.
4. Set source to `Deploy from a branch`.
5. Select `main` and `/ (root)`.
6. Save and wait for deployment.
7. Open the generated GitHub Pages URL.
