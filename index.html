about

From transaction monitoring to network security

I'm a final-year BSc Computer Science student at the University of the West Indies, building toward a career in security operations and network security.

Before this, I spent six years as a Senior Proof Officer at the Bank of Saint Vincent and the Grenadines, monitoring high-volume transaction batches, investigating discrepancies, flagging anomalies, and escalating issues before they became audit findings — all under strict daily deadlines.

That's the same discipline I'm now applying to networks: watch closely, notice what deviates, trace it back, document it, escalate it. I've built that muscle through enterprise GNS3 networking labs (routing, VPNs, ACLs, gateway redundancy), a few full-stack applications with real authentication and deployment concerns, and ongoing AWS and Microsoft Azure security training.

I'm not presenting this as SOC work experience — it isn't. It's the foundation I'm building an entry-level SOC or cybersecurity role on top of.
